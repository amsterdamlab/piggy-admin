# Piggy Master Admin Dashboard 👑

Panel de Administración exclusivo para la gestión integral de Piggy App.

## Características:
- 🔐 Login de Administrador con Supabase Auth y Master PIN
- 👥 CRM de Usuarios, saldos y verificación legal (Habeas Data)
- 🐖 Granja de Piggies, pesaje semanal y estados de engorde
- 🏪 Gestión del Mercado de Cerditos y Aceleradores (CRUD)
- 🥩 Gestión de Tienda (Piggy Gourmet) y Red de Aliados
- ⚡ Creación y gestión de Misiones Flash
- 💰 Aprobación de recargas (Bre-B/QR) y liquidación de retiros
- 📊 Dashboard con Métricas, Top 10 y gráficos en tiempo real
